 SB File Encryptor & Decryptor
A professional-grade file security tool developed with **C#** and **Windows Forms**, designed to provide robust protection for your private and confidential data.

### 🚀 Features of the Application
* **🔑 Password Protection:** Protect all your files with a password of your choice.
* **🔒 Versatile Security:** Secure Office documents, archive files, media files, and more.
* **🗂️ Wide File Support:** Encrypt photos, videos, PDFs, ZIP/RAR archives, and other file types.
* **👤 User-Friendly:** Add strong password protection in just a few clicks.
* **⚡ Efficient Performance:** A fast, simple, and user-friendly file security solution.
* **🕵️ Privacy-Focused:** Prevent unwanted access to your private and confidential files.
* **⚙️ Reliable Technology:** Utilizes reliable encryption technology for maximum data security.

### 💾 Data Policy
This application operates **entirely offline**. It does not collect, transmit, or store any personal data on external servers. All encrypted file data remains on your local device and is never shared with third parties.
