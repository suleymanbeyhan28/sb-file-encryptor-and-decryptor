# SB File Encryptor & Decryptor

A professional-grade file security tool developed with C# and Windows Forms, designed to provide robust encryption and secure protection for confidential files and sensitive data.

![C#](https://img.shields.io/badge/Language-C%23-blue)
![Platform](https://img.shields.io/badge/Platform-Windows-lightgrey)
![License](https://img.shields.io/badge/License-Dual_License-brightgreen)

### 🚀 Features of the Application
* **🔑 Password Protection:** Protect all your files with a password of your choice.
* **🔒 Versatile Security:** Secure Office documents, archive files, media files, and more.
* **🗂️ Wide File Support:** Encrypt photos, videos, PDFs, ZIP/RAR archives, and other file types.
* **👤 User-Friendly:** Add strong password protection in just a few clicks with a modern, responsive UI.
* **⚡ Efficient Performance:** A fast, simple, and asynchronous file security solution built for stability.
* **🕵️ Privacy-Focused:** Prevent unwanted access to your private and confidential files.

### ⚙️ Under the Hood (Technical Specs)
This tool isn't just about a clean UI; it's built on solid engineering principles:
* **Cryptography:** Utilizes industry-standard **AES-256** encryption coupled with **PBKDF2** key derivation for maximum brute-force resistance.
* **Memory Management:** Optimized file streams and array pooling to handle large files efficiently without overloading system RAM.
* **Asynchronous Architecture:** UI remains fully responsive during heavy encryption tasks using `async/await` patterns.
* **DPI Awareness:** Fully scales and looks crisp across different monitor resolutions and scaling factors.

### 💻 System Requirements
To ensure the best performance and prevent UI stuttering during heavy encryption tasks:
* **Minimum:** Windows 10, 4 GB RAM, Dual-Core CPU (Intel Core i3 / AMD Ryzen 3 or equivalent).
* **Recommended:** Windows 10/11, 8+ GB RAM, Quad-Core CPU, SSD Storage.

### 🛠️ How to Run / Installation
1. Clone the repository to your local machine:
```bash
   git clone [https://github.com/suleymanbeyhan28/sb-file-encryptor-and-decryptor.git](https://github.com/suleymanbeyhan28/sb-file-encryptor-and-decryptor.git)
   ```
2. Open the solution (`.sln`) in **Visual Studio 2022** (or newer).
3. Ensure you have the appropriate .NET framework installed.
4. Build and run the project (F5).
